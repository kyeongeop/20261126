        TQL 语法速查
        

          

            
事件字段

            host = "api-01"
            level != "info"
            message ~ "timeout"
            id > 10 / ts >= "2026-11-25T14:00:00Z"
          

          

            
证据标签组合

            #deploy AND NOT #verified
            all_tags("db-lock","timeout")
            any_tags("trace","metrics")
            (#a OR #b) AND #c
          

          

            
前后关系 + 窗口

            level="error" AFTER #deploy WITHIN 20m
            #timeout BEFORE #rollback WITHIN 45m
            LAST 6h AND service="checkout"
            
单位：ms / s / m / h / d；WITHIN 可省略。
